# Relay

### Reliable Event Delivery Platform

Relay is an open-source project built with Elixir and Phoenix, focused on reliable event delivery between applications through webhooks.

The project explores challenges such as asynchronous processing, fault tolerance, concurrency, event persistence, and delivery reliability.

## Motivation

Building reliable integrations between independent applications is not trivial. Network failures, unavailable services, duplicate events, and delivery retries introduce complexity that grows with the system.

Relay is an opportunity to explore and implement solutions to these challenges using the Elixir ecosystem.

## Goals

- Explore Elixir and Erlang/OTP in a practical application.
- Build reliable asynchronous processing workflows.
- Understand fault tolerance and concurrency.
- Implement event persistence, retries, and idempotency.
- Develop an observable and maintainable system.

## Technology
