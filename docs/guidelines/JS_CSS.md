# JavaScript and CSS guidelines

- Use Tailwind CSS classes and custom CSS rules to produce polished, responsive interfaces.
- Tailwind CSS v4 uses this import syntax in `app.css`; retain it for projects generated by `phx.new`:

  ```css
  @import "tailwindcss" source(none);
  @source "../css";
  @source "../js";
  @source "../../lib/my_app_web";
  ```

- Never use `@apply` in raw CSS.
- Write Tailwind-based components manually; do not use daisyUI.
- Only the `app.js` and `app.css` bundles are supported by default.
  - Do not reference external vendor scripts with `src` or stylesheets with `href` in layouts.
  - Import vendor dependencies through `app.js` and `app.css`.
  - Never write inline custom `<script>` tags in templates.
